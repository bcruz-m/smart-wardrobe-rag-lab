# M4.3 Submission — Smart Wardrobe RAG

Independent lab in `dl-school-agentic`. No paid APIs were used for the final results.

**Deviation from the original example:** The workshop example uses OpenAI `text-embedding-3-small` (1536d) and `gpt-4o-mini`. My OpenAI account had no credits (`insufficient_quota`), so I used free local alternatives instead:

- **Embeddings:** `Xenova/all-MiniLM-L6-v2` via Transformers.js, local, 384 dimensions
- **LLM:** `qwen2.5:3b` via Ollama, local, `temperature: 0`, `seed: 42`

Because MiniLM produces 384-dimensional vectors, they are stored in a separate 384d index instead of the 1536d `bootcamp-m43` index, which was left unchanged. The RAG chain is also stricter than the original example. It retrieves first, then the local LLM returns quoted evidence plus an answer, and the code checks each quote against the retrieved chunks. Citations are generated by code from chunk metadata. If the LLM answer fails a grounding check, the verified source quotes are returned instead and labelled as a rule-based fallback.

**Notes on LLM answers and fallbacks**

- **LLM** means `qwen2.5:3b` generated the answer and it passed the grounding checks: verbatim evidence, kept qualifiers, and no words beyond the evidence.
- **Rule-based fallback** means the LLM answer failed the grounding checks even after one repair attempt. For Q4, the LLM overstated "Supabase is not currently connected". The verified source sentences are shown instead.
